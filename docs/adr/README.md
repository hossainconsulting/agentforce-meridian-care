# Architecture and governance decisions

Use these records for significant technical or engineering-policy decisions.
A recorded decision does not establish that its implementation is complete.

| Record | Status | Scope |
|---|---|---|
| [0001: Explicit org targeting and scoped operations](0001-explicit-org-targeting.md) | Accepted policy, recorded retrospectively | Engineering workflow |

## Adding a decision

Copy [the template](template.md) to the next numbered file.
Start new proposals as Proposed. Record actual acceptance evidence before
changing the status to Accepted. Add the record to this index.

Preserve historical decisions. When an approach changes, add a replacement
record and link it from the superseded record.
