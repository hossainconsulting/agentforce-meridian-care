# The Meridian Engagement

> **This is a simulation, not client work.** Meridian Appliance Care Pty Ltd is a fictional company.
> This repository documents a self-directed Salesforce project built to develop
> and evidence implementation skills. No real customer data appears anywhere in it.

**Certification track:** Agentforce Specialist
**Salesforce org:** Developer Edition (CLI alias `devorg`)
**Scope:** 6 weeks | discovery, Service Cloud build, Agentforce agent, ticket operations, reporting and a live incident, executive debrief

## The brief

A six-week consulting engagement for a national warranty service administrator drowning in phone volume, with Agentforce licensed but never switched on.

## What's in here

| Folder | Contents |
|---|---|
| `force-app/` | Salesforce metadata retrieved from the org — the configuration itself |
| `seed/` | Apex scripts that build the starting data, including its deliberate defects |
| `deliverables/` | The written work: design docs, SOPs, analyses, runbooks |
| `evidence/` | Before/after screenshots and test results per phase |

`deliverables/` is the substance. The configuration proves the clicks happened;
the documents prove the thinking did.

## Progress

Build log lives in `deliverables/build-log.md` — every change with its date,
reason, and the requirement it traces to.

## For recruiters and agencies

**What this repository evidences:** Agentforce Specialist design work — a case-management
backbone with the commercial warranty kept separate from the service-level entitlement,
a five-layer guardrails framework applied to a real-shaped client, and a pattern library
that decides which answers an agent may generate and which it must retrieve.

**State as at 06/09/2026:** Design delivered; the Week 2 build and the Week 3 agent are
next. The org is Agentforce-provisioned.

**Read these first (ten minutes):**

1. [`deliverables/ai-guardrails-framework.md`](deliverables/ai-guardrails-framework.md) — the five layers, the control inventory, and the gap register the client must decide
2. [`deliverables/service-agent-pattern-library.md`](deliverables/service-agent-pattern-library.md) — 25 patterns, three risk tiers, Australian compliance notes
3. [`week2-build-brief.md`](week2-build-brief.md) — the ERD, the three relationship decisions, and the coverage formula the agent reads instead of guessing

**How to verify:** every change is in the build log with its date and the requirement it
traces to; corrections are appended, never edited over. The
[skill-to-evidence map](https://portfolio.hossainconsulting.com/#evidence) on the portfolio shows where each certification is
applied, and the [hiring page](https://portfolio.hossainconsulting.com/#hire) says what I am open to.
